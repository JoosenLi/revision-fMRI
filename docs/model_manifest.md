# Model/checkpoint manifest

The machine-readable inventory is [manifests/models.json](../manifests/models.json). It contains **224 unique published model rows**, with each raw results row, original contrast metadata, comparison memberships, loader family, checkpoint locator/status, and no institutional paths. It is generated by `scripts/build_audit_manifest.py` from the pinned source snapshot without importing model code. Reference scores are source metadata only, never optimization targets.

## Identity and confidence

Use the source `model_string` as identity, preserving model/task/diet and raw aliases. The results inventory, not all loaders and not the 226-row contrast table, defines publication membership. Every checkpoint remains **not locally byte verified**: no weights were downloaded. A recovered URL is stronger than a constructor default but is not a verified historical artifact. For inference, additionally require immutable upstream revision, local SHA-256, transform version and explicit candidate-layer manifest. Historical random initializations cannot be recovered from the architecture name alone.

## Exact locators recovered and remaining gaps

| Comparison/family | Recovered reference | Remaining ambiguity |

| Taskonomy | 24 task-specific `*_encoder` entries in visualpriors URL registry; encoder state_dict, not decoder | DeepNSD did not pin visualpriors version; random encoder is separate |
| VISSL SSL | Ten exact URLs including training recipe/phase, retained per row | Verify local files and compatible torchvision ResNet50; classifier/projection/prototypes removed |
| SLIP controlled language set | `https://dl.fbaipublicfiles.com/slip/{simclr,clip,slip}_{small,base,large}_25ep.pt` | Verify file SHA; instantiate from checkpoint args, strip `module.`, strict load, return visual encoder |
| ImageNet1K/21K size | 12 exact timm model-name pairs and diet labels | Untagged defaults and pretraining vs fine-tuning; ResMLP `_in22ft1k` must not be renamed to pure 21K |
| IPCL diet | Exact `ipcl1`, `ipcl7`, `ipcl8`, `ipcl9` URLs under `https://visionlab-pretrainedmodels.s3.amazonaws.com/project_instancenet/ipcl/` | Unequal augmentation/normalization recipes; preserve Places256 vs places2 naming mismatch |
| CLIP overall survey | OpenAI RN50, RN101, ViT-B/32, ViT-B/16, ViT-L/14 URL/hash table | Historical package version unpinned; do not substitute OpenCLIP or LAION-trained CLIP |
| BiT expertise | `https://tfhub.dev/google/experts/bit/r50x1/in21k/{expertise}/1`, converted to ResNetV2 | TensorFlow-to-PyTorch conversion parity and local checkpoint bytes |
| SEER | Exact 32/64/128 GF pretrained and IN-finetuned source URLs | VISSL config version and state mapping |
| Detectron / YOLO / MiDaS / DINO | Source model/config or hub entrypoint | Hub revisions/checkpoints and transform dispatch not fully resolved |

IPCL ImageNet file is `06_instance_imagenet_AlexNet_n5_lr03_pct40_t07_div1000_e100_bs128_bm20_gn_stack_final_weights_only.pth.tar`, not the newer `ipcl6` ImageNet variant. Other diet files are `alexnet_gn_u128_openimagesv6_final_weights_only.pth.tar`, `alexnet_gn_u128_places2_final_weights_only.pth.tar`, and `alexnet_gn_u128_vggface2_lr001_final_weights_only.pth.tar`.

The published inventory also includes two SLIP CC12M entries whose keys say ViT-L but URLs say base and generic metadata says YFCC15M. Record the inconsistency; these are outside `compare_goal_slip`'s nine controlled rows. Do not repair their identity by guessing.

There are 64 rows explicitly labeled random plus `random_weights_taskonomy` labeled taskonomy. The manifest therefore records 65 unresolved random states; this differs from the paper's headline grouping and must not be silently normalized away. The nine controlled SLIP variants use patch-16 visual models at 224 pixels; the small variant is the vendored mocov3-style timm constructor. Model-specific transforms and hook outputs, rather than architecture display labels, define the extracted features.

## Original loaders inspected

DeepNSD `model_options.py`, `model_code/_options.py`, vendored `ipcl_codebase/__init__.py`, SLIP visual-model constructors and source metadata were inspected statically. Upstream [OpenAI CLIP loader](https://github.com/openai/CLIP/blob/d05afc436d78f1c48dc0dbf8e5980a9d471f35f6/clip/clip.py) and [visualpriors Taskonomy loader](https://github.com/alexsax/visual-prior/blob/6abde8bff9aab5422c9657ec57a2e1137ca4fa01/visualpriors/taskonomy_network.py) were separately inspected to resolve URL tables. Those upstream revisions are audit references, **not established original run revisions**. Other historical upstream implementations remain unpinned. Source hashes are in `docs/provenance/source_inventory.json`.

## Per-collaborator configuration

Copy `configs/paths.example.yaml` to `configs/paths.local.yaml` (ignored). Configure data/stimuli/checkpoint/feature/results roots locally; relative roots resolve against the config file, not working directory. `REVISION_FMRI_CONFIG` may point to an alternative ignored local YAML file. Shared model records contain logical keys and scientific provenance only. Keep local checkpoint bindings in that ignored file. Loading is offline and must fail on absent/mismatched bytes. Installing/importing this package does not import torch, load models, download weights or start jobs.

## First executable compatibility adapter

`TorchvisionAlexNetLoader` now implements offline `alexnet_classification` loading
and the released PIL classification transform. See [offline vision](offline_vision.md)
for the pinned compatibility environment, config binding and validation limits.
All historical checkpoint identities remain unresolved; this adapter does not
change any publication-manifest approval or verification status. Other model
families and complete dataset extraction remain unimplemented; see
[the single-batch hook API](feature_hooks.md) for the implemented primitive.
